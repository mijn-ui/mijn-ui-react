# @mijn-ui/react-core

The theme, utilities and hooks shared by every MijnUI component: the Tailwind CSS v4 theme (`theme.css`), `cn`, `createContext`, `mergeRefs`, `useControlledState`, the unstyled-slot helpers and `extendVariants`.

[Documentation](https://mijnui.vercel.app/docs/react)

## Installation

```sh
npm install @mijn-ui/react-core
```

Import the theme in your global CSS, after Tailwind:

```css
@import "tailwindcss";
@import "@mijn-ui/react-core/theme.css";
```
