# @mijn-ui/react-breadcrumb

A breadcrumb trail that shows where the current page sits in a hierarchy, with links back to its parents.

[Documentation](https://mijnui.vercel.app/docs/react)

## Installation

```sh
npm install @mijn-ui/react-breadcrumb
```
