# @mijn-ui/react-charts

Lightweight, token-driven charts: bar, grouped bar, donut, sparkline, and legend.

[Documentation](https://mijn-ui.vercel.app/react/docs/components/charts)

## Installation

```sh
npm install @mijn-ui/react-charts
```
